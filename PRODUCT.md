# Ivan Rozak — Portfolio

## Platform
Web, built with Next.js App Router, React, and TypeScript.

## Purpose
Help prospective clients understand Ivan's fullstack engineering work, explore relevant projects, and start a conversation by email.

## Confirmed content
- Twelve projects in `lib/data.ts`; Lumina is excluded.
- RasaRasa and Kasheer contributions cover their websites. RasaRasa's API and app are future work.
- Pixelleven is Ivan's personal project; Yuk Puncak is a solo engineering project.
- Do not invent years, metrics, testimonials, or responsibilities.
- Approved tagline: “A collection of websites and products I’ve helped build.”

## Approved direction
Use the Wonder Marquee First alternative. Keep the interface monochrome, project imagery in color, and the overall presentation minimal, modern, simple, and elegant. Use Lenis and Motion for satisfying, accessible animation.

## Visitor path
Homepage project preview → searchable/filterable Projects archive → project website or email enquiry. Mobile preview uses manual swipe; names always remain visible.
